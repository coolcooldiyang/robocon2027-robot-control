# ROBOCON 2027 上位机使用说明

源码与文档仓库。Windows免安装上位机请到 [Releases](https://github.com/coolcooldiyang/robocon2027-robot-control/releases/latest) 下载 `Robocon2027_host.zip`，解压后运行 `Robocon2027.exe`。当前机械臂限速上限为 **10 rad/s**。

更新日期：2026-11-01。适用于角度/末端坐标双模式上位机，配套新固件为 `Robocon2027_angle_cartesian.hex`。

## 当前配置

整车包含全向底盘、前后两组升降、一条四关节机械臂及合并吸盘气路 YV2+YV3。机械臂接 CAN2，全部使用 MIT 模式。

| 关节 | 电机 | 功能 | 角度范围（rad） | 当前固件 Kp / Kd |
|---|---|---|---|---|
| ID1 | DM4340 | 第一个 pitch 轴 | 0～2.5 | 500 / 5 |
| ID2 | DM4340 | 第二个 pitch 轴 | 0～5 | 300 / 5 |
| ID3 | DM4340 | 第三个 pitch 轴 | 0～5 | 50 / 2 |
| ID4 | DM6220 | 末端旋转 | -6.28～6.28 | 5 / 0.1 |

Kp/Kd 以固件 `Lib/arm.h` 为准，上位机角度帧不携带增益。ID2 的目标和反馈不取反。反转夹爪及第二条机械臂已移除。

## 接线和启动

控制和反馈共用 USART1，固定 **921600 / 8N1**，3.3 V TTL，共地。

| DAP 串口 | 单片机 | 用途 |
|---|---|---|
| TX | PA10 / USART1_RX | 向单片机发送控制帧 |
| RX | PA9 / USART1_TX | 接收单片机状态帧 |
| GND | GND | 共地 |

1. 双击 `dist/Robocon2027.exe` 或源码目录的 `start.bat`；便携包解压后直接运行 `Robocon2027.exe`。EXE 自带运行环境。
2. 选择 DAP 对应的 COM 口，点击“连接”。连接后只接收，尚未发送控制指令。
3. 遥控器 CH4 高使能、CH5 高切到自动。首次有效回传会填充机械臂和升降目标。
4. 设置并检查目标，再点击“开始发送 · 50 Hz”。开始发送时底盘速度归零，机械臂按设定限速跟随目标。

本次坐标帧需重新烧录配套新固件。COM 号以当前设备枚举为准。

当前配套固件还包含 USART3 的 JY901P 读取任务（PD9 RX / PD8 TX，115200 / 8N1）。要启用此次新增读取任务，需要烧录重新生成的 `Robocon2027_JY901P_USART3.hex`；发布目录中的 `Robocon2027_host_IK_angle_frame.hex` 也已同步为相同镜像。陀螺仪角度仅供单片机内读取，未加入当前上位机画面或 23 字节状态帧。

最新固件已将 `gyro_attitude.yaw_deg` 改为连续多圈角度，新增 `yaw_raw_deg` 保留原始 ±180° 值。对应 `Robocon2027_JY901P_yaw_continuous.hex`；上述两个固件文件也同步为相同版本。连续化采用相邻合法样本的最短角差，要求样本之间的真实转动小于 180°。

2026-11-01 固件 `Robocon2027_yaw_rate_PD_zero.hex` 包含零偏航角速度 PD：`set_vw==0` 时将角速度补偿加到 `vw_clamp`，不要求 vx/vy 非零，静止时也可保持；`set_vw!=0` 时退出并清零补偿。target=0 deg/s，反馈为 JY901P Z 轴角速度。Kp/Kd 初值均为 0，当前不产生补偿，供确认极性后调试。传感器须主动输出 `0x52` 角速度帧；无有效角速度或主动转向时补偿清零。串口断流仍将输入目标置零，但 set_vw=0 时保留角速度保持；全车失能使用 CH4。此功能抑制偏航角速度，不包含绝对航向角反馈；角速度PD功能保留在本次双模式固件中。当前发布固件别名均同步为本次版本。

默认需要有效回传才能开始发送；超过 600 ms 没有新回传，会停止控制发送并尝试发送底盘零速。仅接 DAP TX 时可勾选“仅发送接线（无回传）”并按提示操作，此时无法同步实际位置。坐标逆解在停止发送时仍要求新鲜反馈作为参考角度。

## 选择角度帧或坐标帧

打开“整车控制与坐标逆解”，下滚至“05 / 坐标逆解与电机限幅”。**串口发送**下拉框可在停止发送时选择：

- **角度帧（上位机解算）**：默认且兼容旧固件。可直接用ID1～4滑条/数值框，也可输入末端坐标后点击“应用坐标 / 求逆解预览”，由上位机解算成角度再发送。
- **坐标帧（单片机解算）**：上位机发X/Y及姿态模式，单片机逆解成角度并限速执行。需新固件及双向接线，不能使用“仅发送接线”。ID1～3滑条仅预览，ID4仍独立控制旋转。

坐标帧的操作步骤：

1. 连接并获取有效回传，选择“坐标帧（单片机解算）”。切换帧类型会清除已应用坐标。
2. 选择“自动选择姿态（只输入 X、Y）”或“固定连杆3姿态”。自动模式禁用姿态框；固定模式额外输入连杆3相对X轴绝对姿态（界面deg，协议mrad）。
3. 输入X/Y（mm），点击“应用坐标 / 求逆解预览”。程序保存应用时的坐标与模式，单纯编辑输入框或切换姿态选项不会立即改变已应用目标。
4. 检查预览和目标，点击“开始发送”。发送中再次点击应用才更新坐标；帧类型下拉框锁定，先停止发送才能切换。
5. 查看“MCU机械臂状态”。上位机预览仅供参考，即使预览无解仍可应用坐标供MCU校验；MCU无解时保留四关节上一目标。反馈图才表示关节实际回传推算的末端。

例如(175,178) mm固定30°没有限幅内解，自动姿态可以找到。自动姿态优先接近参考关节角，结果可能随参考变化。角度模式无合法逆解会拒绝更新关节目标。两种模式均只检查几何与电机限幅，不限制相交、重合或路径。关节插值不保证末端沿直线；输出角度量化1 mrad，末端有小量偏差。模型见[机械臂解算说明](kinematics_model.md)。

## 机械臂画面和整车控制

启动默认显示“机械臂画面与末端坐标”。图形按 425 / 425 / 200 mm 连杆长度等比例绘制，位置终点为 ID4 中心。

| 画面信息 | 含义 |
|---|---|
| 蓝色实线、目标末端 X/Y/φ | 当前关节目标的正解预览 |
| 绿色虚线、反馈末端 | 有效回传角度的正解；无回传或过期时隐藏 |
| 最后下发末端 | 角度帧显示写出角度的正解；坐标帧显示实际写出的X/Y及姿态选项，关节以MCU反馈为准 |

四关节滑条与数值框双向联动，并与整车控制页同步。ID4 旋转不改变所建模的 ID4 中心位置。发送值和回传值都不代表执行确认，状态帧没有电机在线或到位标志。

- 底盘 vx、vy 范围 ±2 m/s，wz 范围 ±3.2 rad/s。方向按钮按住行驶、松开停车；滑条速度持续生效，按“底盘停车”或 Esc 清零。切出窗口也会将底盘归零。
- 前后升降各为 0～420 mm，可选快速模式。
- 吸盘“保持 / 同时吸气 / 同时释放”同时控制 YV2、YV3。
- 机械臂限速范围 0.02～10 rad/s，默认 0.30 rad/s；三个 pitch 关节同步插值，ID4 独立跟随。
- “用当前反馈填充目标”在停止发送且回传有效时使用。
- 停止发送、断开或关闭窗口会先尝试发送底盘零速。固件在自动模式连续 300 ms 未收到有效控制帧时将底盘清零，机械臂、升降、吸盘保持最后指令。
- “底盘停车”仅停止底盘；全车失能使用遥控器 CH4。CH4 低时固件失能并释放吸盘。

## 串口帧：角度和末端坐标双模式

USART1：921600 / 8N1，PA9 TX、PA10 RX。多字节整数均为**大端序**，偏移从 0 开始。控制帧仍为 30 字节，状态帧仍为 23 字节。**byte28 为机械臂模式标志**，只改变机械臂载荷的解释，底盘、升降和吸盘字段保持原位置。

### 控制帧：30 字节

| 偏移 | 类型与含义 |
|---|---|
| 0 | 0xCC |
| 1～2、3～4、5～6 | vx、vy、wz，int16；10000 = 1 m/s 或 1 rad/s；分别限幅 ±20000、±20000、±32000 |
| 7～8、9～10 | 前、后升降目标，uint16，0～420 mm |
| 11 | 升降模式：0=normal，1=fast |
| 12～13 | mode=0：ID1 目标 int16 mrad；mode=1/2：X int16，单位 **0.1 mm** |
| 14～15 | mode=0：ID2 目标 int16 mrad；mode=1/2：Y int16，单位 **0.1 mm** |
| 16～17 | mode=0：ID3 目标 int16 mrad；mode=1：连杆3绝对姿态 φ int16 mrad；mode=2：忽略，填0 |
| 18～19 | 所有模式：ID4 目标 int16，-6280～6280 mrad |
| 20～21 | mode=0：保留填0；mode=1/2：关节限速 uint16 mrad/s，0=默认300，非零限幅20～10000（0.02～10 rad/s） |
| 22～23 | 保留填0 |
| 24 | YV2+YV3：0=保持，1=同时吸气，2=同时释放 |
| 25～27 | 保留填0 |
| **28** | **0=四关节角度；1=X/Y+固定 φ，由单片机逆解；2=仅X/Y，由单片机自动选姿态** |
| 29 | 0xEE |

模式0角度限幅：ID1=0～2500、ID2/3=0～5000、ID4=-6280～6280 mrad。ID2不取反。模式1/2的 X/Y 支持有符号 -3276.8～3276.7 mm，实际仍须满足机械臂几何工作空间及电机限幅。φ 为连杆3相对水平X轴的绝对姿态，**不是 ID3 电机角，也不是 ID4 旋转角**。ID4始终独立控制。

例如固定 (800,200) mm、φ=30°、ID4=-1 rad、限速0.30 rad/s：byte12..21依次为五个大端整数 `8000,2000,524,-1000,300`，byte28=1；仅指定 (175,178) mm 则为 `1750,1780,0,-1000,300`，byte28=2。

模式1/2由 `Lib/arm_kinematics.c` 求解，优先选择接近当前保持指令的合法角度；相同坐标载荷缓存，不随50 Hz重复帧重新选择分支。未准备好关节反馈时重试；无合法解或未知模式时，**四个关节均保留上一有效目标**，该帧底盘/升降/吸盘仍正常处理。成功结果量化为1 mrad并按限速进行关节插值，ID1～3同步跟随，ID4独立限速；这不保证末端直线运动。只检查几何可达性和电机限幅，不筛选相交、重合或路径。

### 状态帧：23 字节

| 偏移 | 类型与含义 |
|---|---|
| 0 | 0xCC |
| 1～2、3～4 | 前、后升降实际高度，uint16 mm；0xFFFF=该组无可用高度 |
| 5～7 | 占位0 |
| **8** | **0xC2：支持本版角度/坐标双模式协议** |
| 9～10、11～12、13～14、15～16 | ID1～4 当前反馈，int16 mrad |
| 17～20 | 保留0 |
| **21** | **机械臂命令状态：0=正常；1=未知模式；2=无合法逆解；3=关节反馈尚未准备** |
| 22 | 0xEE |

状态帧在CH4高、CH5高时约50 Hz回传。状态0只表示没有命令错误，**不是到位确认**；状态帧没有请求序号、执行确认或电机在线标志，无法逐帧关联目标。坐标和姿态不直接回传，界面用关节反馈正解计算实际末端。

旧角度帧的 byte28=0，可继续控制新固件。**坐标帧必须烧录新固件**；旧固件会把X/Y误当关节角。上位机仅在600 ms内有效回传的byte8=0xC2时允许开始发送坐标，坐标模式不支持无回传接线；发送中回传超时会停发并尝试底盘零速。

## 开发和验证

源码入口 `app.py`，协议 `protocol.py`，解算 `kinematics.py`，画面 `arm_view.py`。Python 3.10+，源码目录执行：

```powershell
pip install -r requirements.txt
python app.py
python -m unittest test_console test_kinematics test_collision -v
python -m PyInstaller --noconfirm --onefile --windowed --name Robocon2027 app.py
```

当前 53 项测试通过，覆盖固定姿态与自动姿态逆解、(175,178)、随机可达点、限位边界、UI 联动、角度/坐标帧、能力检查、应用目标暂存、断线和超时。`test_collision.py` 中的碰撞模型仅作离线工具测试，不是当前控制限制。`verify_dual_mode.py` 对实际ARM编译产物验证了固定/自动逆解、随机可达点、限幅、模式切换、失败保留目标与坐标模式限速；原MIT编码、USART1收发、300 ms超时、JY901P和偏航角速度PD回归均通过；尚未进行实机运动测试。

日志为 `%LOCALAPPDATA%/Robocon2027/console.log`，自动轮转。配套固件工程为 `MDK-ARM/A_board.uvprojx`；当前采用 FreeRTOS 10.3.1 GCC/ARM_CM4F 端口兼容 ArmClang 6，CubeMX 重新生成后应核对端口路径及 USART1 DMA 配置。
