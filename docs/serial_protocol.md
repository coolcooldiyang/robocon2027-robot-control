# ROBOCON 2027 单机械臂配置与串口协议

更新日期：2026-11-01。适用于单机械臂角度/末端坐标双模式固件与上位机。

## 电机配置

机械臂接 CAN2，全部为 MIT 模式。角度单位为 rad，目标角度与电机反馈同向，已去掉旧左臂 ID2 的取反。

| CAN2 ID | 型号 | Kp | Kd | 目标角度范围 |
|---|---|---|---|---|
| 1 | DM4340 | 500 | 5 | 0～2.5 |
| 2 | DM4340 | 300 | 5 | 0～5 |
| 3 | DM4340 | 50 | 2 | 0～5 |
| 4 | DM6220（库中枚举 DMG6220） | 5 | 0.1 | -6.28～6.28 |

参数集中在 `Lib/arm.h`。机械限幅分别在串口解析和 CAN 控制发送前执行。MIT 编码仍使用型号参数表范围，不能把编码范围改为机械限幅：DM4340 为 P_MAX=12.5、V_MAX=10、T_MAX=28；DM6220 为 P_MAX=12.5、V_MAX=45、T_MAX=10，需与电机内部配置一致。

控制使用目标速度 0、前馈转矩 0，按各关节 Kp/Kd 保持目标位置。原位置模式的 slow/fast 速度参数已移除，`lift_mode` 仅影响升降；角度模式由上位机发送平滑角度目标；坐标模式由单片机进行关节限速。

## 机构与遥控

- 移除第二条机械臂（原 CAN2 ID5、6 不再使能、失能、发送控制或解析反馈；ID4 改为单臂第四关节）。
- 移除 hcan3 上的反转夹爪电机和 YV1 夹爪气缸控制。
- 吸盘气路合并，YV2、YV3 同时吸气、同时释放，遥控切换也同步执行。hcan3 MCP2515 保留用于发送吸盘电磁阀状态。
- CH4 高：使能底盘和单臂；CH4 低：失能、底盘速度清零、吸盘释放。
- CH5 低：手动；CH5 高：自动。
- 手动模式 CH6 高 + CH7 上升沿切换吸盘，CH8 控制原前后升降。
- 使能后等待各关节的新反馈，手动模式以限幅后的当前位置作为保持位置。自动模式收到有效控制帧后使用上位机目标。MIT 保持指令在两种模式下持续刷新。
- 自动切回手动后保持最后下发的目标；重新使能会清除机械臂目标有效标志，等待控制帧更新。
- 自动模式下 300 ms 没有收到有效串口控制帧，底盘 vx/vy/wz 清零；机械臂、升降和吸盘保持最后指令。恢复有效帧后继续控制。

## 串口帧：角度和末端坐标双模式

USART1：921600 / 8N1，PA9 TX、PA10 RX。多字节整数均为**大端序**，偏移从 0 开始。控制帧仍为 30 字节，状态帧仍为 23 字节。**byte28 为机械臂模式标志**，只改变机械臂载荷的解释，底盘、升降和吸盘字段保持原位置。

### 控制帧：30 字节

| 偏移 | 类型与含义 |
|---|---|
| 0 | 0xCC |
| 1～2、3～4、5～6 | vx、vy、wz，int16；10000 = 1 m/s 或 1 rad/s；分别限幅 ±20000、±20000、±32000 |
| 7～8、9～10 | 前、后升降目标，uint16，0～420 mm |
| 11 | 升降模式：0=normal，1=fast |
| 12～13 | mode=0：ID1 目标 int16 mrad；mode=1/2：X int16，单位 **0.1 mm** |
| 14～15 | mode=0：ID2 目标 int16 mrad；mode=1/2：Y int16，单位 **0.1 mm** |
| 16～17 | mode=0：ID3 目标 int16 mrad；mode=1：连杆3绝对姿态 φ int16 mrad；mode=2：忽略，填0 |
| 18～19 | 所有模式：ID4 目标 int16，-6280～6280 mrad |
| 20～21 | mode=0：保留填0；mode=1/2：关节限速 uint16 mrad/s，0=默认300，非零限幅20～10000（0.02～10 rad/s） |
| 22～23 | 保留填0 |
| 24 | YV2+YV3：0=保持，1=同时吸气，2=同时释放 |
| 25～27 | 保留填0 |
| **28** | **0=四关节角度；1=X/Y+固定 φ，由单片机逆解；2=仅X/Y，由单片机自动选姿态** |
| 29 | 0xEE |

模式0角度限幅：ID1=0～2500、ID2/3=0～5000、ID4=-6280～6280 mrad。ID2不取反。模式1/2的 X/Y 支持有符号 -3276.8～3276.7 mm，实际仍须满足机械臂几何工作空间及电机限幅。φ 为连杆3相对水平X轴的绝对姿态，**不是 ID3 电机角，也不是 ID4 旋转角**。ID4始终独立控制。

例如固定 (800,200) mm、φ=30°、ID4=-1 rad、限速0.30 rad/s：byte12..21依次为五个大端整数 `8000,2000,524,-1000,300`，byte28=1；仅指定 (175,178) mm 则为 `1750,1780,0,-1000,300`，byte28=2。

模式1/2由 `Lib/arm_kinematics.c` 求解，优先选择接近当前保持指令的合法角度；相同坐标载荷缓存，不随50 Hz重复帧重新选择分支。未准备好关节反馈时重试；无合法解或未知模式时，**四个关节均保留上一有效目标**，该帧底盘/升降/吸盘仍正常处理。成功结果量化为1 mrad并按限速进行关节插值，ID1～3同步跟随，ID4独立限速；这不保证末端直线运动。只检查几何可达性和电机限幅，不筛选相交、重合或路径。

### 状态帧：23 字节

| 偏移 | 类型与含义 |
|---|---|
| 0 | 0xCC |
| 1～2、3～4 | 前、后升降实际高度，uint16 mm；0xFFFF=该组无可用高度 |
| 5～7 | 占位0 |
| **8** | **0xC2：支持本版角度/坐标双模式协议** |
| 9～10、11～12、13～14、15～16 | ID1～4 当前反馈，int16 mrad |
| 17～20 | 保留0 |
| **21** | **机械臂命令状态：0=正常；1=未知模式；2=无合法逆解；3=关节反馈尚未准备** |
| 22 | 0xEE |

状态帧在CH4高、CH5高时约50 Hz回传。状态0只表示没有命令错误，**不是到位确认**；状态帧没有请求序号、执行确认或电机在线标志，无法逐帧关联目标。坐标和姿态不直接回传，界面用关节反馈正解计算实际末端。

旧角度帧的 byte28=0，可继续控制新固件。**坐标帧必须烧录新固件**；旧固件会把X/Y误当关节角。上位机仅在600 ms内有效回传的byte8=0xC2时允许开始发送坐标，坐标模式不支持无回传接线；发送中回传超时会停发并尝试底盘零速。

## 运动学与验证

模型以ID1中心为原点，X水平向前，Y向上；425/425/200 mm三连杆，电机零位连杆绝对角为-9°/162°/30°。theta1=q1-9°，theta2=q1-q2+162°，theta3=q1-q2+q3+30°；末端位置到ID4中心，ID4旋转不改变该点位置。固件固定姿态解析枚举两支，自动姿态用q1可行边界分段并细化选解，只检查几何和电机限位。

配套文件 `Robocon2027_angle_cartesian.hex`，必须重新烧录才能接收坐标帧。角度模式由上位机限速，坐标模式由单片机按byte20..21限速，默认300 mrad/s。速度指关节速度，不是末端mm/s。

Keil AC6构建0错误、0警告。实际ARM产物仿真验证150个固定姿态随机目标、30个自动姿态随机目标、边界与重合姿态、(175,178)自动模式及固定30°拒绝、能力标识与错误码、反馈未准备重试、无解保留全部四关节、重复帧缓存、模式切换和坐标限速。原USART1、角度帧、300 ms超时、JY901P与偏航角速度PD回归通过。上位机53项测试通过，尚未进行实机运动验证。
